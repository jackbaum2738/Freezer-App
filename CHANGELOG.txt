FREEZR CHANGELOG
================

Versioning: x.0.0 = major (new features) | 1.x.0 = minor (small additions/changes, batched) | 1.0.x = patch (tiny fixes/tweaks)


2.0.0 -- 2026-08-27
--------------------
- Added item categories: each item now has a category (Meat, Poultry, Fish & Seafood, Vegetables, Fruit, Bread & Bakery, Ready Meals & Leftovers, Dairy & Ice Cream, Other by default), shown as a tag on each list row and searchable.
- New category is suggested automatically from the product name via built-in keyword matching (no external AI call — keeps the app dependency-free and offline-friendly), same as the item detail popup, before Save.
- The app learns a barcode's category the first time you set it, the same way it already learns item names, so the same product defaults to the same category on future scans (works in single-item add, batch mode, and the item detail popup).
- Added a Categories settings page (⚙️ button next to backup) to rename, add, or delete categories at any time. Renaming or deleting a category updates every item using it (deleted categories fall back to "Other"). Open to everyone for now; could be restricted to an administrator later.

1.2.0 -- 2026-08-27
--------------------
- Added a Backup button (download icon next to search) that exports your full inventory as a JSON file.
- Added Batch scan mode: a toggle (Add stock screen only) that lets you scan a whole stack of barcodes without stopping to name each one, then review and name them all at once afterward via a "Review batch" screen. Validates every item has a name before committing.
- Added an Opened/Sealed toggle to the item detail popup, staged the same way as name and quantity (only applies on Save). Shown as a small "Opened" badge on the list when set. Applies to the oldest unit in a grouped item, since that's the one you'd typically reach for first.
- Cleaned up a harmless duplicate internal function found while working on this batch.

1.1.0 -- 2026-08-27
--------------------
- Fixed the item detail popup so quantity changes are staged just like the name field, instead of applying live: tapping +/- no longer touches the shared list immediately.
- Close/X now discards ALL unsaved changes (name and quantity together) instead of only skipping the name.
- Save now commits name and quantity together in one update and closes the popup, with a single toast summarizing what changed.

1.0.3 -- 2026-08-27
--------------------
- Reverted Enter-to-save on the item detail name field -- quantity can also be adjusted from that popup, so pressing Enter while editing the name no longer risks closing/saving early. Save now only happens when the Save button itself is tapped.

1.0.2 -- 2026-08-27
--------------------
- Fixed the quantity "-" button showing literal text instead of a minus sign.
- Renamed "Save name" button to "Save" in the item detail popup.
- Fixed Save not working when pressing Enter/Done on the keyboard while editing a name (was only wired to the button tap).

1.0.1 -- 2026-08-27
--------------------
- Renamed the "Start scanning" button to "Scan items" (in both Add and Remove modes).

1.0.0 -- 2026-08-27
--------------------
- Restarted versioning from scratch with a proper major.minor.patch scheme (previous ad-hoc "2.1" label retired).
- Added this changelog -- every future change gets logged here going forward.

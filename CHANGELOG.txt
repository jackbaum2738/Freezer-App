FREEZR CHANGELOG
================

Versioning: x.0.0 = major (new features) | 1.x.0 = minor (small additions/changes, batched) | 1.0.x = patch (tiny fixes/tweaks)


1.0.3 -- 2026-08-27
--------------------
- Reverted Enter-to-save on the item detail name field -- quantity can also be adjusted from that popup, so pressing Enter while editing the name no longer risks closing/saving early. Save now only happens when the Save button itself is tapped.

1.0.2 -- 2026-08-27
--------------------
- Fixed the quantity "-" button showing literal text instead of a minus sign.
- Renamed "Save name" button to "Save" in the item detail popup.
- Fixed Save not working when pressing Enter/Done on the keyboard while editing a name (was only wired to the button tap).

1.0.1 -- 2026-08-27
--------------------
- Renamed the "Start scanning" button to "Scan items" (in both Add and Remove modes).

1.0.0 -- 2026-08-27
--------------------
- Restarted versioning from scratch with a proper major.minor.patch scheme (previous ad-hoc "2.1" label retired).
- Added this changelog -- every future change gets logged here going forward.
